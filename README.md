# 🌐 Network Engineering Portfolio

Selamat datang di repositori portofolio jaringan saya. Repositori ini berisi kumpulan simulasi, perancangan arsitektur, dan konfigurasi jaringan yang saya bangun menggunakan *network simulator* berstandar industri seperti GNS3, Cisco Packet Tracer, dan RouterOS (MikroTik).

---

## 🛠️ Tech Stack & Core Competencies

- **Vendors & OS:** MikroTik (RouterOS v7/CHR), Cisco (IOS)
- **Simulators & Tools:** GNS3, Wireshark, Cisco Packet Tracer, Winbox
- **Networking Concepts:** 
  - **L2 / Switching:** VLANs, Inter-VLAN Routing, Switching Protocols
  - **L3 / Routing:** Static Routing, Dynamic Routing (OSPF, BGP), Subnetting (VLSM/CIDR)
  - **Services & Security:** DHCP Server/Client, NAT (Masquerade/Dst-NAT), Firewall Filtering Rules, VPN
